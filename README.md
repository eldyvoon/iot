# React + TypeScript + Vite

to run the project:

```
npm install
npm run dev
```

to run the tests:

```
npm run test
```

---

## Note

These tasks could also be solved using these npm packages, which in real-world projects would be more appropriate because there's no need to reinvent the wheel:

- **Task 1 (RunningClock)** → `react-timer-hook`
- **Task 2 (isCycle)** → `graphology`
- **Task 3 (UserList)** → `@tanstack/react-query`
